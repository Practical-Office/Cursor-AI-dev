# Workshop Agenda — Five-Day Cursor + Matt Pocock Skills Course

**Duration:** 5 full days (or compressed 3.5-day intensive)  
**Audience:** Competent software engineers with basic Cursor experience  
**Artifacts:** Published Course HTML (`docs/`), this agenda, living process, certification evidence pack  
**Living process:** CURSOR-MATT-SKILLS-PROCESS.md  
**Certification:** Evidence Pack + lead review (`docs/certification.html`)

> Facilitator plan only — not a slide deck.  
> Point learners at the live pages; use this table for timing.

---

## Prerequisites (before the room)

| Who | Action |
|-----|--------|
| Learners | Complete **Setup** (setup.html) — skills installed, `/setup-matt-pocock-skills` run once in their own repo |
| Facilitator | Confirm live site or local `python3 -m http.server` in `docs/` |
| Facilitator | Print or share quick-reference.html |
| Facilitator | Have real backlog items ready for each pair (or seeded tickets) |

If Setup is incomplete for most of the room, spend the first block verifying installs before Module 1.

---

## Day 1 — Reality Check & Core Setup (≈ 7.5 h)

| Block | Time | Content | Facilitator notes |
|-------|------|---------|-------------------|
| 0 | 15 m | Hub Why + principles | First-draft speed is not scored. Rework is. |
| 1 | 20 m | Native tools speedrun | Chat vs Composer Agent — one live diff only |
| 2 | 20 m | Install + setup gate | `/setup-matt-pocock-skills` must succeed per student repo |
| 3 | 60 m | Taxonomy + triage table | User-invoked vs model-invoked; `/wayfinder` vs `/grill-with-docs` |
| 4 | 80 m | Paired triage + grill | Mandatory committed CONTEXT.md / ADR artifact |
| 5 | 75 m | Three Pillars deep dive | Practice Engineering, Assumption Destruction, Stress Testing |
| 6 | 90 m | Extended practice + artifact critique | Every pair’s artifact inspected |
| Close | 30 m | Recap + homework | Overnight triage + grill with artifact |

**Hard stop/start:** Stop defaulting every item into `/grill-with-docs`. Start triage first.

## Day 2 — Advanced Grilling + Specification

| Block | Time | Content | Facilitator notes |
|-------|------|---------|-------------------|
| 0 | 20 m | Homework audit | Reject any missing triage reasoning or artifact |
| 1 | 15 m | Triage gate | Foggy → `/wayfinder`; clear → `/grill-with-docs` |
| 2 | 70 m | Three Pillars advanced | Live weak vs strong grill |
| 3 | 90 m | Heavy grilling practice | Destroyed assumptions list required |
| 4 | 75 m | `/to-spec` | Synthesis only; three mandatory sections |
| 5 | 90 m | Grill → Spec + section critique | Reject incomplete specs on the spot |
| Close | 30 m | Recap + homework | Overnight grill → 3-section spec |

**Hard stop/start:** Stop accepting specs missing any of the three mandatory sections.

## Day 3 — Tickets + Implementation

| Block | Time | Content | Facilitator notes |
|-------|------|---------|-------------------|
| 0 | 20 m | Spec audit | Reject incomplete sections |

## Day 4 — Debug, Review, Architecture, Prototype

| Block | Time | Content | Facilitator notes |
