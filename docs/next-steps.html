3 · Module re-run

Request a module re-run

If a module day did not land (artifacts missing, chain skipped, or you are stuck), ask a human lead or facilitator — do not keep prompting the agent to “make it work.”

Include in your ask:

  • Module # (or Setup) and what failed or is incomplete
  • Repo path and links to evidence you already tried
  • What you already tried (skills run, errors, CI output)

When stuck: stop. Escalate with repo path and context — same bar as module escalate strips on Setup and Modules 1–5.

4 · Common failure modes

When the chain breaks

  • Routing fog — using /grill-with-docs when /wayfinder fits (or the reverse) without a one-sentence routing reason.
  • Skipped grill or weak context — jumping to /to-spec without priming @ docs or finishing assumption destruction.
  • Honor-system progress mistaken for unlock — sidebar checklists are self-reported only, not certification or CI.
  • External skill names — following dev-sops hubs that teach banned flows (/to-issues, typed refactor-in-loop /tdd) instead of this course chain.
  • Evidence Pack without #8 — submitting certification without the throwaway /prototype verdict (artifact 8 is required on full/intensive schedules).
  • Print as full course — treating learner-summary-only PDF as a substitute for interactive modules.
  • Prompting past stuck — continuing agent loops instead of escalating to a human lead with repo path and what you tried.
