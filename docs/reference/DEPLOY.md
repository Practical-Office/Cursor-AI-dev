# Deployment

GitHub Pages is built from the `/docs` folder on the `main` branch.

1. Ensure all HTML modules (index.html, setup.html, module-1.html … module-5.html, quick-reference.html, certification.html) exist under `docs/`.
2. Settings → Pages → Source: Deploy from a branch → `main` / `/docs`.
3. Site will be available at https://practical-office.github.io/Cursor-AI-dev/

Until the HTML conversion is complete, the Markdown sources in `docs/reference/` and `docs/index.md` are the working content.
