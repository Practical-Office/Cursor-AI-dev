Cursor + Matt Skills

Disciplined Cursor work for a new Dev: triage before grill, implementable specs, tracer-bullet tickets, Red→Green only, dual-axis review. Measured by rework reduction — not first-draft speed.

Why

Why a shared Cursor process matters

Most new Cursor users treat the agent as autocomplete. Accept → ship → discover mess later. Without a common chain, engineers invent prompt habits and ship unreviewed AI diffs. This course installs one end-to-end path so the team produces committed domain artifacts, ticket-kill-test tickets, and CI-green implement loops — not theater.

Principles: Triage decision procedure first (one-sentence reasoning before grill) · Three Pillars (Context Engineering, Assumption Destruction, Stress Testing) · Spec synthesis only (acceptance criteria + non-goals + residual risks) · Ticket binary kill test (one-sentence user-observable behavior + non-circular blockers) · Red→Green only in /implement · Must-fix same day · Prototypes are throwaway · Domain decisions require committed CONTEXT.md / ADR.

Skills chain: /setup-matt-pocock-skills → triage (/wayfinder | /grill-with-docs) → /to-spec → /to-tickets → /implement → /code-review. Full skill pages: hub Skills.
