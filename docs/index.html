Before you start

Prerequisites

  • Cursor Agent or Composer access
  • Node/npm installed
  • Git commit rights on a real repo
  • ≥1 backlog item ready

Why

Why a shared Cursor process matters

Most engineers treat the agent as autocomplete. Accept → ship → discover mess later. Without a common chain, teams invent prompt habits and ship unreviewed AI diffs. This course installs one end-to-end path so engineers produce committed domain artifacts, slice-test tickets, pre-Build review, and CI-green implement loops — not theater.

Principles: Route before grill (one-sentence routing decision before any grilling skill — see Module 1) · Three Pillars (Context Engineering, Assumption Destruction, Stress Testing) · Spec synthesis only (/to-spec publishes; it does not interview — see Module 2) · Ticket slice test (one-sentence user-observable behavior + non-circular blockers; reserve kill test for BML) · Red→Green only in /implement · Must-fix same day · Prototypes are throwaway · Domain decisions require committed CONTEXT.md / ADR.

Skills chain: /setup-matt-pocock-skills → route (/wayfinder | /grill-with-docs; tracker /triage when issues need label movement) → /to-spec → /to-tickets → pre-Build review → /implement (auto /code-review). Glossary →
