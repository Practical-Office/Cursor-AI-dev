Before you start

Why this exists

What you leave able to do

  • Install mattpocock/skills into Cursor.
  • Run /setup-matt-pocock-skills once in a real repo and show inspectable output.
  • State the Rules vs Skills difference (see below).

Rules vs Skills

Always-on vs on-demand

  • Rules = always-on static context in .cursor/rules/ (short, specific, point at examples). Loaded every session.
  • Skills = on-demand workflows invoked by typing /skill-name. Cost context only when invoked.

Hard gate

No Module 1 until setup output (tracker, labels, domain-doc layout) exists in your own repo. Evidence Pack fails if missing.

Exact steps

Install and verify

  1. Cursor open on the Agent surface. That is where you build. A side chat is for a question that must not steer the main thread. See the note below.
  2. npx skills@latest add mattpocock/skills -a cursor
  3. Select the engineering skills and setup-matt-pocock-skills. If this repo was installed before October 2026, run npx skills@latest update, then add again, so skills added on the v1.3.x line are present.
  4. Open your real working repo.
  5. Run /setup-matt-pocock-skills; answer tracker, labels (only if triage is installed), and doc layout.
  6. Verify GLOSSARY.md (or the path setup recorded) and docs/adr/. If you installed /triage, also verify docs/agents/triage-labels.md. Setup skips that labels file when triage is not installed. A repo that indexes several glossaries uses GLOSSARY-MAP.md. Skills read only those names. If an older setup left a differently named glossary, rename it (the previous filename is in the living-process changelog).
  7. Plan to run the same commands CI runs before you call /implement done. mattpocock/skills v1.3.x does not ship a pre-commit setup skill.

Agent surfaces · October 28, 2026

Where this course runs

Work the chain in the local Cursor Agent. The three surfaces below are current. They are not a substitute for the install, and this course does not grade or certify them. Day 1 repeats this note: Module 1.

  • Cloud agents run in a Cursor-managed environment and can produce interactive canvases.
  • Remote control lets you see and reply to a local agent from the Cursor iOS app. The agent stays on your computer. Enterprise organizations keep it off until an admin turns it on.
  • Agent SDK packages an agent you ship as a folder (instructions.md, tools/, on-demand skills/). Start with npx @cursor/agent-sdk init. That packaging is not how you install mattpocock/skills into the repo you are learning in.
